CSS: dùng để trang trí giao diện cho trang HTML

CSS là gì?

CSS là ngôn ngữ dùng để điều khiển cách hiển thị của các tài liệu HTML. Nó xác định cách các phần tử được hiển thị trên trình duyệt – bao gồm bố cục, màu sắc, phông chữ, và các hiệu ứng trực quan khác.

Các thuộc tính CSS

Nhóm: Văn bản

-Thuộc tính:color

Chức năng: Đổi màu chữ

Ví dụ: color: red;

-Nhóm: Văn bản

Thuộc tính: font-size

Chức năng: Kích thước chữ

Ví dụ: font-size: 16px;

-Nhóm: Văn bản

Thuộc tính: text-align

Chức năng: Căn lề chữ

Ví dụ: text-align: center;

-Nhóm: Văn bản

Thuộc tính: font-family

Chức năng: Font chữ

Ví dụ: font-family: Arial;

-Nhóm: Văn bản

Thuộc tính: font-weight

Chức năng: Độ đậm chữ

Ví dụ: font-weight: bold;

-Nhóm: Kích thước

Thuộc tính: width / height

Chức năng: Chiều rộng / cao

Ví dụ: width: 100px;

-Nhóm: Nền

Thuộc tính: background-color

Chức năng: Màu nền

Ví dụ: background-color: yellow;

-Nhóm: Nền

Thuộc tính: background-image

Chức năng: Hình nền

Ví dụ: background-image: url('img.jpg');

-Nhóm: Viền

Thuộc tính: border

Chức năng: Viền bao quanh

Ví dụ: border: 1px solid black;

-Nhóm: Viền

Thuộc tính: border-radius

Chức năng: Bo góc

Ví dụ: border-radius: 10px;

-Nhóm: Khoảng cách

Thuộc tính: margin

Chức năng: Khoảng cách bên ngoài

Ví dụ: margin: 20px;

-Nhóm: Khoảng cách

Thuộc tính: padding

Chức năng: Khoảng cách bên trong

Ví dụ: padding: 10px;

-Nhóm: Hiển thị

Thuộc tính: display

Chức năng: Kiểu hiển thị (block, inline,...)

Ví dụ: display: flex;

-Nhóm: Hiển thị

Thuộc tính: visibility

Chức năng: Ẩn/hiện phần tử

Ví dụ: visibility: hidden;

-Nhóm: Vị trí

Thuộc tính: position

Chức năng: Định vị phần tử

Ví dụ: position: absolute;

-Nhóm: Flexbox

Thuộc tính: justify-content

Chức năng: Căn chỉnh ngang

Ví dụ: justify-content: space-between;

-Nhóm: Flexbox

Thuộc tính: align-items

Chức năng: Căn chỉnh dọc

Ví dụ: align-items: center;
